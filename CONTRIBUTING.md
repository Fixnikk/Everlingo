# Contributing / Участие в проекте

- Bugs and ideas: open an Issue / Ошибки и идеи: создавайте Issue.
- Run `npm test` before a pull request / Перед pull request запустите `npm test`.
- The app is a single file `index.html` on purpose: no build step, no dependencies / Приложение намеренно в одном файле `index.html`: без сборки и зависимостей.
- New JSON fields must be documented in `docs/JSON_FORMAT.md` and `docs/JSON_FORMAT.ru.md`, and in the in-app manual / Новые поля JSON описывайте в обоих файлах `docs/JSON_FORMAT*` и во встроенной инструкции.
- Translations of the README and docs are welcome (`README.xx.md`) / Переводы README и документации приветствуются (`README.xx.md`).
