# Формат JSON

[English](JSON_FORMAT.md) · [Русский](JSON_FORMAT.ru.md)

Файл может быть: **курсом** (`lessons[]`), одним **уроком** (объект с `exercises`) или **массивом уроков**. Можно загрузить сразу несколько файлов («Заменить курс» склеивает их в новый курс, «Добавить к текущему» дописывает уроки; урок с тем же `id` заменяется, прогресс сохраняется).

## Курс

| Поле | Описание |
|---|---|
| `title` | Название курса. По нему же хранится прогресс |
| `description` | Необязательно |
| `srs` | Необязательно. **Без него повторов нет.** См. ниже |
| `settings` | Необязательно. См. ниже |
| `lessons[]` | Уроки: `id`, `title`, `theory`, `srs`, `exercises[]` |

## Задания

| `type` | Поля |
|---|---|
| `choice` | `question`, `options[]`, `answer` (текст варианта или номер с 0) |
| `input` | `question`, `answer` (строка или массив допустимых ответов), `hint` |
| `order` | `question`, `answer` (верное предложение), `extra[]` (лишние слова), `words[]` (свой набор слов) |
| `match` | `question`, `pairs` вида `[["слово","перевод"], ...]`, минимум 2 |

У любого задания можно указать `id` (уникальный; по нему хранится прогресс, поэтому не меняйте его при правках), `explanation` (показывается после ответа) и `srs` (свои правила).

При проверке `input` и `order` регистр и знаки `. , ! ? ; : « » " “ ”` не учитываются. Буквы с диакритикой (ö, ä) учитываются.

## Теория

`theory` урока показывается перед первым занятием. Это строка, массив блоков или `{ "title": "...", "blocks": [...] }`. Блок — строка (абзац) или объект:

| `type` | Поля |
|---|---|
| `text` | `text` |
| `list` | `items[]` |
| `table` | `rows` (массив массивов), `header: true` — первая строка заголовок |
| `example` | `text`, `translation` |
| `note` | `text` |

В тексте работают `**жирный**` и `\n` (перенос строки).

## Интервальное повторение (`srs`)

```json
"srs": { "intervals": [1, 3, 7, 14, 30], "failDays": 2 }
```

- `intervals`: через сколько дней повторять после 1-го, 2-го, 3-го… верного ответа подряд (последнее значение повторяется)
- `failDays`: через сколько дней повторить после ошибки (0 — в следующем занятии). Ошибка сбрасывает цепочку
- `"srs": {}` или `true` включает повторы со значениями по умолчанию
- Приоритет: `srs` задания → `srs` урока → `srs` курса. `false` отключает повторы на этом уровне

## Настройки (`settings`)

| Поле | По умолч. | Что делает |
|---|---|---|
| `retryWrong` | `true` | Ошибочное задание спрашивается ещё раз в конце занятия |
| `shuffle` | `true` | Перемешивать задания (`false` — в порядке файла) |
| `sessionSize` | `0` | Максимум заданий за занятие (0 — без лимита) |
| `unlock` | `"none"` | `"sequential"`: урок открывается, когда в предыдущем отвечены все задания |
| `dailyGoal` | `0` | Цель в XP на день (0 — выключено) |
| `xp` | `10` | XP за верный ответ с первой попытки |
| `mastery` | `3` | Сколько верных ответов подряд нужно, чтобы задание считалось выученным |

## Запрос для нейросети

> Составь JSON-курс для платформы JSON-Lingvo: {title, description, srs (необязательно), settings (необязательно), lessons:[{id,title,theory,exercises}]}. Типы заданий: choice (question, options, answer), input (question, answer — строка или массив), order (question, answer, extra), match (question, pairs). У каждого задания уникальный id. Тема: … Уровень: … Сделай 3 урока по 8 заданий, в начале каждого — короткая теория. Верни только JSON.
