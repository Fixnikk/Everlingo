Платформа для обучения по образцу Duolingo, которая работает из **одного HTML-файла**. Уроки пишутся обычным JSON: вы загружаете файл и занимаетесь. Интервальное повторение необязательно и целиком настраивается в самом JSON.

> Интерфейс приложения пока только на русском. **Содержимое курсов может быть на любом языке.** Перевод интерфейса есть в планах.

## Зачем

Обычные приложения привязывают вас к своим курсам. Здесь наоборот: любой учитель, ученик или нейросеть может подготовить файл урока, а приложение превратит его в задания, страницы теории и расписание повторов. Ни сервера, ни регистрации, ни слежки: прогресс хранится в вашем браузере.

## Возможности

- 4 типа заданий: выбор ответа, ввод текста, сборка предложения, сопоставление пар
- Страницы теории перед уроком (текст, списки, таблицы, примеры, заметки)
- **Необязательное** интервальное повторение: нет блока `srs` — нет повторов. Правила задаются для курса, урока или отдельного задания
- Настройки курса в JSON: повтор ошибок, перемешивание, размер занятия, последовательное открытие уроков, дневная цель XP, XP за ответ, порог «выучено»
- Загрузка сразу нескольких JSON-файлов; добавление уроков к существующему курсу
- Отметки о пройденных уроках; серия дней, XP и дневная цель
- Встроенная инструкция с кнопкой «Скопировать всю», резервная копия и сброс прогресса
- Работает без интернета; portable-версия для Windows (`.exe`) лежит в Releases

## Быстрый старт

| Способ | Как |
|---|---|
| В браузере | Откройте `index.html` двойным щелчком. Ничего устанавливать не нужно |
| Онлайн-демо | Включите GitHub Pages (см. [docs/PUBLISHING.md](docs/PUBLISHING.md)) |
| Windows | Скачайте `JSON-Lingvo-portable.exe` из [Releases](../../releases) |

Нажмите **«Загрузить JSON»** и выберите файл, например [`examples/sample-course.json`](examples/sample-course.json).

## Минимальный файл урока

```json
{
  "title": "Мой курс",
  "lessons": [{
    "id": "l1", "title": "Урок 1",
    "exercises": [
      { "type": "choice", "question": "Как по-шведски «привет»?", "options": ["Hej", "Tack"], "answer": "Hej" }
    ]
  }]
}
```

Чтобы включить интервальное повторение, добавьте на верхний уровень `"srs": {}`. Полный формат: **[docs/JSON_FORMAT.ru.md](docs/JSON_FORMAT.ru.md)**. Такая же инструкция встроена в приложение (кнопка «Инструкция»).

## Как работает повторение

Верный ответ с первой попытки назначает следующий повтор через 1, 3, 7, 14 и 30 дней (можно изменить). Ошибка сбрасывает цепочку и назначает повтор через `failDays` (по умолчанию 2). Без блока `srs` ничего не планируется, а кнопка «Повторить» скрыта.

## Разработка

```bash
npm install
npm test            # сквозной тест в jsdom (35 проверок)
```

Сборка portable-версии для Windows (на Windows или в CI):

```bash
cd electron
npm install
npm run dist        # -> electron/dist/JSON-Lingvo-portable.exe
```

При публикации тега вида `v1.0.0` GitHub Actions соберёт exe и приложит его к релизу.
